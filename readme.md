# AI红娘(婚恋产品的智能对话推荐agent功能演示)

一个用于展示智能对话推荐服务的演示项目。主要使用性格标签作用户匹配和推荐

项目原型：

婚恋产品，有脱单需求的恋爱候选用户集在注册时已经填入自己的性格标签、爱好标签、游戏标签、职业、地域、年龄、收入、教育背景等信息。该agent用于引导在线用户交流期望恋爱对象的信息，并根据在线用户在会话中提到的期望信息对候选用户集打分，从而推荐更符合在线用户期望的候选恋爱对象

本项目仅展示根据性格标签、爱好标签、游戏标签打分的逻辑，重点展示性格标签

产品设计的性格标签包括注重相互陪伴,注重仪式感,温柔细心,情绪稳定,思维敏锐,对待感情专一,懂得换位思考等，推荐系统需要根据在线使用聊天agent的用户对话中的性格描述匹配到这些性格标签上，从而计算候选用户分数

演示数据为模拟生产数据结构随机生成的2000条mock性格标签数据，爱好标签和游戏标签全部置空

模型接口使用：测试了qwen-flash、qwen-max、deepseek-flash，目前deepseed-flash的效果最好，deepseek-flash已经能较好地解析性格短语并匹配到性格标签

### 对原型项目的精简处理：
1. 省略了长对话记忆功能，没有保留历史对话中的关键信息，只根据当前session信息做推荐
2. 省略了根据推荐召回算法、信息完整度、用户活跃度、用户质量等方式缩小候选用户集的过程
3. 省略了根据性别、地域等条件过滤用户的过程，只生成2000条mock数据存在csv文件中做测试
4. 打分步骤中省略了职业、教育背景等信息

## 性格匹配方式：
在产品中先设定好特定性格标签。候选恋爱对象用户集已经提前选好了性格标签并计算好每个标签的bm25分数
 - bm25：针对文本长度增加惩罚项，计算候选恋爱对象和该性格标签的关联程度。候选恋爱对象的所属性格标签越多，每个性格标签的关联程度就越低
1. 在对话agent中引导用户对期望的恋爱对象性格进行描述，用大语言模型提炼出用户偏好的性格描述短语和不喜欢的性格描述短语
2. 在线用户期望的恋爱对象性格维度：包括外向、内向、计划性、开放性、宜人性、情绪稳定性。
3. 在线用户期望的性格描述与设定性格标签的相似度：sbert embedding余弦相似度
4. 大模型api直接用对话中的性格描述匹配性格标签，作为sbert embedding的校验，以ndcg分值评判sbert embedding是否合理

## 匹配方式解析

### sbert embedding匹配：
最直接的通过embedding相似度匹配的方式

sbert更适合短语映射。测试后选择shibing624/text2vec-base-chinese模型

### 大语言模型api直接映射到性格标签：
最简单的方式。经测试后发现每次匹配会有一些差异，所以仅把它作为embedding 匹配的检验方式

由于api每次匹配结果不同，但是相对顺序不变，所以用ndcg检验（ndcg是个针对推荐结果先后排序的评估指标）

举例如下：

正例：

1. 温柔体贴

| 性格标签 | sbert相似度|
|------|------|
| 温柔细心 | 0.8805 |
| 注重相互陪伴 | 0.6954 |
| 懂得照顾人 | 0.6537 |
| 善解人意 | 0.5679 |
- - api结果：温柔细心,善解人意,懂得照顾人
- - ndcg：0.99


2. 不骄不躁

| 性格标签 | sbert相似度|
|------|------|
| 情绪稳定 | 0.6255 |
| 沉稳冷静 | 0.5653 |
- - api结果：情绪稳定,沉稳冷静
- - ndcg：1.00

反例：

| 性格描述 | api返回结果|sbert匹配结果|结论|
|------|------|------|------|
| 能活跃气氛 | 外向开朗,幽默风趣,阳光乐观,亲和力强 | / |需增加维度：外向、内向|
| 对自己要求高 | 事业心强,善于规划 | / | 需增加维度：对未来的规划（计划性）|
| 生活有目标 | 事业心强,善于规划 | / | 需增加维度：对未来的规划（计划性）|
由以上反例提炼出了一些性格维度，并匹配到当前通用人格测试里常用的一些性格维度
### 性格维度设计：
按照外向、内向、计划性、开放性、宜人性、情绪稳定性几个维度设计。
- 外向：出自MBTI中的E/I维度(E)
- 内向：出自MBTI中的E/I维度(I)
- 计划性：出自MBTI中的J/P维度(J)。善于组织、计划，下决心快
- 开放性：出自大五人格OCEAN(O)。反映对新经验和想法的接受度
- 宜人性：出自大五人格OCEAN(A)。描述人际互动风格。高分者友善、合作、富有同情心、信任他人、乐于助人 。
- 情绪稳定性：出自大五人格OCEAN(N)。指情绪稳定性程度。低分者情绪稳定、冷静、抗压能力强、不易受负面情绪影响 。

举例如下：
- 温柔体贴

- 幽默风趣，能活跃气氛
- - 外向: 1.0, 内向: 0.0 , 计划性: 0.0 , 开放性: 0.0, 宜人性: 0.0, 情绪稳定性: 0.0
- 完美主义，对自己要求高
- - 外向: 0.0, 内向: 0.0 , 计划性: 1.0 , 开放性: 0.0, 宜人性: 0.0, 情绪稳定性: 0.0
- 经济独立, 生活有目标
- - 外向: 0.0, 内向: 0.0 , 计划性: 1.0 , 开放性: 0.0, 宜人性: 0.0, 情绪稳定性: 0.0


## 最终得分计算方式：
性格分数：性格维度分数和embedding匹配分数的加权求和

总分：性格分数、爱好分数、游戏分数加权求和

分数权重可在utils.py文件中配置。

## 产品功能开发和对应代码文件入口

### 推荐系统
根据聊天内容提取关键信息，并对候选用户打分做出推荐
生产系统需用户点击推荐按钮触发

代码入口：recommend.py

测试数据在preference.json中，可直接修改并运行recommend.py查看推荐结果

### 聊天系统
从性格、爱好、游戏、职业几个方面引导用户对期望的恋爱对象做出描述，描述信息足够的时候引导用户点击“找对象”按钮触发推荐

样例如下：
- 小牵：你好呀，我是小牵～今天想先从最让你心动的点聊起：你希望对方是什么样性格的人呢？
- 你：(输入) 我喜欢幽默风趣，能活跃气氛的人
- 小牵：幽默又会活跃气氛的人，真的很招人喜欢呢～那平时你都喜欢做些什么来放松自己呀？
- 你：(输入) 我喜欢王者荣耀
- 小牵： 打王者荣耀挺带感的～那平时除了游戏，你还会喜欢做点什么来放松自己呢？
- 你：(输入) 没有什么兴趣爱好，平时生活挺单调的
- 小牵： 生活偶尔单调也没关系呀～那关于工作，你希望对方是怎样的职业类型呢？
- 你：(输入) 工作都可以，随缘吧
小牵： 好的呢，你已经分享了这么多，真棒～现在可以点击「找对象」按钮，看看系统为你匹配的合适人选啦！


代码入口：chat.py

### mock数据生成

随机生成2000条测试数据做测试。每个用户的每个性格标签都会计算bm25的值作为用户的该标签偏重，bm25分值考虑了针对用户所选标签总数的惩罚项

本项目代码里只生成性格标签，测试时也可以加入爱好标签和游戏标签

代码入口：generate_data.py

生成结果写在data/candidate_demo.csv中
